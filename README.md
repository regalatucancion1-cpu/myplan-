# Mi Plan de Déficit

App web instalable (PWA) con el plan de dieta: registro de peso, menú del día, recetario, lista de la compra y guía para comer fuera.

- Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
- Los datos de cada persona se guardan solo en su dispositivo; aquí no hay datos personales.
- `index.html` se genera desde las fuentes de la app; no lo edites a mano.
